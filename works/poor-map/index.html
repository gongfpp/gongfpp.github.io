穷鬼地图

发现附近折扣门店与优惠活动的 React 应用，接入高德地图，公开可访问的静态演示。

更多界面 / 2 张

把「今天哪儿便宜」做成一张地图：按位置筛出附近有折扣的门店与活动，点开看具体优惠。用 React 搭界面、高德地图承接地理能力，成品以静态站点发布，打开即用。

做了什么
  • 地图与列表双视图联动，按距离与折扣类型筛选
  • 纯前端静态部署，无需后端即可公开演示
  • 门店与优惠数据抽成独立配置，换城市只改数据不改代码
