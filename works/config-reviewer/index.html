配置评审台

面向 Windows 内网环境的配置与资料评审桌面工具，扫描 ZIP 或目录，按模块导出结构化结论。

更多界面 / 2 张

把「一堆散落的配置和文档要逐项核对」这件事做成可重复的流程：扫描压缩包或本地目录，按模块审阅配置与文档，输出结构化结论并留存历史，支持定时任务与仓库拉取更新。

做了什么
  • Tauri + Rust 实现桌面端，产物是 Windows 离线安装包，适配无外网环境
  • 评审结论按模块组织并可导出，历史可回溯，便于多人复核同一批资料
  • 定时任务自动拉取更新并触发评审，把周期性核对从人工改成常驻
