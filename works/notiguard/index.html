消息哨兵 NotiGuard

Android 原生通知与短信关键字监听，命中后走系统通知、跨应用悬浮窗、声音或震动提醒。

实时监听系统通知与短信，对自定义关键字做匹配，命中后立即提醒。监听来源、关键字列表与提醒方式全部可配。读取其它 App 的通知与短信是 Android 独有能力，因此只做 Android，不做 iOS 的等价实现。

做了什么
  • 基于 NotificationListenerService 监听全系统通知，基于 ContentObserver 监听短信收件箱
  • 命中后用 TYPE_APPLICATION_OVERLAY 做跨应用悬浮窗，不打断当前操作
  • 在 README 里明确写出锁屏可见与悬浮窗的隐私风险，并给出规避建议
技术栈
KotlinJetpack ComposeNotificationListenerServiceAndroid 8.0+
