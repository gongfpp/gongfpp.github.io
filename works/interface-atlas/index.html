界面图谱 Interface Atlas

前端设计概念百科：从口语描述找到专业术语，每个概念都有可运行的 Live Demo。

更多界面 / 2 张

把视觉风格、组件、交互模式、动效、页面、设计基础、无障碍这些天天遇到却叫不出名字的东西，整理成可检索、可交互、可交给 AI 的参考库。它不教框架怎么用，而是让人和 AI 助手先在同一套词汇上对齐。

做了什么
  • 支持口语检索：描述「加载时灰色一闪一闪」能找到骨架屏 Skeleton Loading
  • 每条目配真实可运行的 Live Demo，而不是截图或 GIF
  • 提供 When to Use / When NOT to Use 与易混淆概念辨析，另附机器可读的 JSON 与 Markdown
