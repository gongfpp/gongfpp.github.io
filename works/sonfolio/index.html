声迹 Sonfolio

本地优先的 Android 语音记录：把持续录音整理成可阅读、可搜索、可回听的对话时间线。

更多界面 / 1 张

在后台持续录音，自动做语音检测与转写，把相邻语音合并成一场对话，再按日期整理成时间线。录音、识别和基础整理默认都在手机上完成，不需要账号，也不依赖自建后端。

做了什么
  • 打通「录音 → 转写 → 检索 → 回听」整条链路，本地识别与外部 API 识别可切换
  • 音频按对话切分而非按文件堆叠，检索时能按日期与内容定位到具体一段
  • 接 CI 做构建校验，用版本号管理 dev 迭代，按 GPL-3.0 开源
